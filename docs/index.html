Arecibo Zero

Can a mind with no shared language and no built-in knowledge learn arithmetic from a message alone?

We write transmissions. The receivers are freshly initialised neural networks that read nothing but the transmission. Then they sit an exam of sums that never appeared in the message. Then we flip roles and decode an unknown message by reading the mind of a network trained on it.

The setup

Sender, channel, stranger, exam

01 · senderWritePick a number system and what to talk about: sums, products, comparisons, counting. Fixed bit budget.
02 · channelTransmitAs symbols, or as raw bits with unknown word width and random bit flips.
03 · receiverListenA randomly initialised transformer or LSTM learns to predict the next symbol of the message. Nothing else.
04 · examAnswerSums whose operand pairs never appeared, in either order. Only a receiver that found the rule can answer.

A quarter of all operand pairs below 64 are held out of every message. The exam is posed in the message's own symbols, prefixed by a real stretch of the transmission, and graded on the full answer.

Finding 3 · the channel

Raw bits, no word boundaries, cosmic noise

The receiver gets only 0s and 1s and is never told that symbols are 5 bits wide. Bits flip at random. The sender can repeat every bit three times, but repeats count against the budget.

Finding 4 · role reversal

Reading a mind to read a message

Now we are the receivers. A message arrives in a design we don't know: radix, digit order and symbol meanings are hidden, and the symbols are shuffled. We train a network on it, then decipher the message by questioning that network.

  1. Which symbols are digits? The network expects digits to be able to repeat ("11") and expects them in the same places as one another. Operators are never expected twice in a row.
  2. Which symbol separates a count? The operator that chains numerals: a ⋄ b ⋄ c ⋄ …
  3. What is each digit worth? Ask it to count. We splice "x ⋄" into the message and score every one- and two-digit continuation. The digit that is nobody's successor is zero. The two-symbol successor of the last digit is "10", and the order of its two symbols reveals whether digits are written most- or least-significant first.
  4. What do the operators mean? With numerals decoded, the symbol pattern a ⊕ b ⊜ c that makes statements true as sums is "+", the one that makes them true as products is "×", and the one whose single-symbol answer depends only on which side is bigger is a comparison, with its three results.
